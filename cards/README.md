# Founding Colonist cards

Opt-in colonists place shareable assets here (never résumés or selfies).

## Naming
- `MC-####-<classname>-id-card.png` — Founding Colonist ID (**required** on opt-in)
- `MC-####-<classname>-welcome-letter.png` — Welcome letter (optional)
- `MC-####-<classname>-avatar.png` — square cel-cartoon (optional)

## How to add
1. Opt in after Manifest Assignment + ID card.
2. Add your ID PNG under `cards/` with the naming above (PR if you lack write access).
3. Open/update a Founding Colonist Issue linking the card (markdown image).

Never upload résumés or original selfies.
